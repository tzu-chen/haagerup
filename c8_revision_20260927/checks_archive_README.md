# Scope of the revision checks archive

This archive contains the two limited Lean formalizations, fresh exact
replay summaries and logs, the supplemented source ledger, document audit,
resource controls and review notes for the 27 September 2026 manuscript.
The separate `hi_cft_c8_proof_sources.zip` contains the four TeX sources
and their README, review register and final build log.

The checks archive is a review package. It omits the large historical
lattice inputs, the Mathlib checkout and compiled dependencies. Replaying
the listed lattice commands requires the original repository files bound
by the ledger. Hashes authenticate files; they do not prove their contents.
The Lean README and manuscript appendix state the mathematical scope of
each check. The full VOA and annulus arguments are not formalized in Lean.

The final annulus proof supersedes the A1-open status recorded during
earlier stages of the analytic audit notes. The final manuscript and
review register give the current mathematical status.
